# GridDividend

This repository contains a standalone Jupyter Notebook for exploring GridDividend-style utility/customer value sharing.

This model is intended for exploratory and educational purposes. Results depend heavily on assumptions regarding utility capital spending, load growth, DER adoption, avoided costs, and regulatory frameworks.

## Citation

If you use this work in research or publications, please cite:

Currie, R. (2026). GridDividend: Open Source Utility Shared Savings Framework. GitHub Repository.

## How to use

1. Clone the repository
2. Open the notebook, explore and adjust the parameters
3. Run all cells (the notebook is entirely self-contained and installs all required libraries)
